# ADR 0008: The app is GPL-3.0-only

**Status:** accepted (2026-10-08), the user's decision, before the first public release (M10b).

## Context

Until now the licence was undecided, so dependencies were kept permissive and no GPL code was copied: that left every option open. M10b needs a decision. The notices, the code-signing options and a public GitHub repository all depend on it.

The options considered:
- **closed source;**
- **permissive** (MIT/Apache-2.0);
- **copyleft** (GPL-3.0);
- **MPL-2.0;**
- **source-available** (PolyForm, BSL).

What made the difference:
- **Trust.** This app lets other people control your PC. Visible source helps strangers trust it, and helps the outside review of the room-joining crypto.
- **Keeping it open.** With GPL-3.0, a modified version that is distributed must stay open. A permissive licence would allow a closed, paid fork.
- **Related projects.** Sunshine and Moonlight, the closest open projects, are GPL-3.0. Under GPL-3.0 their code can be reused, with attribution, instead of only read.
- **Every dependency is compatible:**
  - the Rust crates are permissive;
  - FFmpeg is LGPL, dynamically linked;
  - SDL3 is zlib;
  - the drivers are BSD-3-Clause and MIT.

## Decision

- **The licence:** **GPL-3.0-only**. `LICENSE` is the FSF's text, checked against its published SHA-256. Every crate inherits it (`license.workspace = true`), and so does `apps/desktop/package.json`.
  - "-only" because that is the literal choice. "-or-later" would also accept GPL versions the FSF publishes in future; switching to it later is easy while the user is the only author.
- **Dependencies stay permissive by policy** (`deny.toml`), which keeps the notices simple. A GPL-3.0-compatible copyleft crate needs a recorded exception.
- **FFmpeg stays the LGPL build,** shipped unmodified as separate DLLs. A GPL build (for x264) would now be allowed, but would be its own decision.
- **Code from other projects** is allowed only under a GPL-3.0-compatible licence, and never silently:
  - its copyright notice is kept;
  - the source (project, file, commit) is named where it is used;
  - it is listed in the third-party notices.

  AGPL (RustDesk) and GPL-2.0-only code need the user's decision first.

## Consequences

- **Distributing the installer means following the GPL:** the app's source must be available to everyone who gets it. Publishing the repository, or including a written offer, covers that.
- **The notices are due with every installer** (M10b's next item): GPL for the app, LGPL and its source offer for FFmpeg, and the other components' notices.
- **The signing options widen:** SignPath's free programme requires an OSI-approved licence, which this is.
- **Relicensing later** needs every contributor's agreement. It is easy while the user is the only author; outside contributions would need a contributor agreement first if that should stay easy.
- **AI-assisted code:** how much copyright protects code written with AI assistance is unsettled in many places. That can weaken enforcement of the GPL's conditions, but doesn't change what the project offers.
